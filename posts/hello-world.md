# Hello, World：从零开始做个人博客

这是我写的第一篇博客文章，用来记录搭建 GitHub Pages 博客的过程。

## 为什么做博客

很多时候，我们会在学习和实践中积累很多知识，但这些知识经常散落在笔记、文档和聊天记录里。写博客的意义，就是把这些零碎的内容整理成一份可持续积累的记录。

## 选择 GitHub Pages

GitHub Pages 是一个非常适合个人博客和项目展示的方案。它的优点包括：

- 免费
- 简单
- 直接托管在 GitHub 上
- 适合技术文章和个人记录

## 最小可用方案

一个简单的博客通常至少包含：

- 首页
- 文章列表
- 文章正文
- 样式文件

例如：

```text
.
├── index.html
├── style.css
├── posts/
│   └── hello-world.md
└── README.md
```

## 发布流程

1. 在 GitHub 上创建仓库
2. 把网页文件上传
3. 在 Settings → Pages 中开启 GitHub Pages
4. 选择 `main` 分支
5. 保存并访问网站

## 结语

写博客不是为了追求完美，而是为了让思考有一个落点。只要开始写，就已经迈出了第一步。

> 记录生活，记录学习，记录成长。
