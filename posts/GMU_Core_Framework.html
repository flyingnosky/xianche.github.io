GMU Core Framework

2026-08-29 • 6 min read

GMU Core Framework 支持在不同 adreno GPU 代际与 GPU 交互提供通用层。该框架处理内存管理、IOMMU mapping、clock control、trace 数据处理，以及 GMU 通用的交互基础。

Core Architecture

GMU Core Framework 是 KGSL 驱动和特定代 GMU 实现（例如 A6XX、GEN7）之间的独立与平台的 layer。它提供所有 GMU 实现要求的通用服务，并允许特定 GEN 的操作通过 gmu_dev_ops 函数指针来调用。

System Structure

从架构上看，这个框架把平台无关的公共能力集中在一层，避免不同 GPU 代际在内存、时钟和 trace 流程上重复实现。 这有助于统一交互接口，减少代际差异带来的维护成本。

关键职责

  • 统一内存相关管理逻辑
  • 处理 IOMMU 映射与地址权限管理
  • 提供统一的 clock control 接口
  • 集中处理 trace 数据采集和通用分析流程
  • 作为 KGSL 与具体 GMU 实现的抽象桥接层

设计价值

这个设计的核心价值在于：把“差异化实现”从“公共能力”中拆离出来。这样平台代码更稳定，特定 GPU 版本只需要关注自己独有的功能和寄存器行为，通用逻辑则由框架统一维护。
